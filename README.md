# Tilevania 🎍

**Tilevania** is a 2D platformer game developed with Unity. Explore the levels, jump across platforms, climb ladders, avoid deadly traps, defeat enemies, and collect coins as you make your way to the finish line.

Sounds simple enough... until the level decides otherwise. 👀

##  Gameplay 🎮

Your goal is to reach the end of each level with just 3 LIVES while surviving the obstacles and enemies along the way.

### Controls

| Input               | Action            |
| ------------------- | ----------------- |
| `A` / `D`           | Move left / right |
| `W` / `S`           | Climb up / down   |
| `Space`             | Jump              |
| `Left Mouse Button` | Shoot             |

**Tip:** Play in fullscreen mode for the best experience!

## ✨ Features

- 2D platforming with responsive movement.
- Tile-based levels with platforms, ladders, and environmental hazards.
- Enemies to fight and obstacles to avoid.
- Shooting mechanics.
- Collectible coins.
- Health and score UI.
- Dedicated scenes for the start menu, gameplay, game over, and winning screen.

## 🛠️ My Additions & Improvements

This project started as a learning project based on a Unity 2D game development course. Along the way, I made additional changes to build on what I learned and make the game feel more complete.

- **Start Menu:** Added a dedicated scene to introduce the game before starting a run.
- **Game Over Screen:** Added a separate scene for when the player loses.
- **Winning Screen:** Added a dedicated scene to show when the player completes the game.

These additions helped me practice working with Unity scenes, game flow, and transitions between different gameplay states.
